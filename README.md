# 个人秋招工作台

> 一个**零依赖单文件 HTML** 的求职投递管理与模拟面试工具。双击即用、离线可跑、可部署分享。

秋招投了十几家公司后，表格管状态太容易滞后，面试准备也全靠临时搜面经 —— 于是自己动手做了这个工作台：投递进度看板化，面试题目跟着目标岗位走，写完答案还能交给 AI 打分复盘。

---

## 功能

### 视图一 · 投递看板

- **六列看板**：待投递 / 已投递 / 简历筛选中 / 面试中 / Offer / 已拒绝，卡片**拖拽即改状态**
- **进度追踪**：面试轮次记录（一面 / 二面 / 三面 + 日期）、投递日期与面试日期均可直接编辑
- **状态时间线**：状态变更 + 面试记录按时间合并展示，连续重复项自动归并，不再凌乱
- **筛选与排序**：按公司、状态、关键词筛选；导出 JSON 备份 / 导入恢复
- **链接解析**：粘贴招聘链接自动识别公司名与岗位名（Boss 直聘等站点有反爬，此时改为手动录入）

### 视图二 · 模拟面试

- **岗位自适应题库**：选中目标岗位后，系统根据岗位名 + JD 自动识别方向，「岗位专业题」整区切换
  - 六大方向专业题包：市场品牌 / 运营 / 产品 / 数据 / 技术 / 设计
  - 题面自动带入公司名与岗位名（如「为什么选择 XX 公司的 XX 岗位？」）
- **JD 定制题包**：把 AI 生成的题包 JSON 粘贴导入，题目自动挂到对应投递记录
  - 工具栏「让 AI 按岗位出题」一键拼好提示词（JD 全文 + 简历 + 输出要求），复制发给 AI 即可
- **按需揭晓的答题框架**：默认只看到题目和输入框，先自己写；写完后点「看参考思路」才展开框架 —— 避免直接抄
- **AI 点评闭环**：单题或批量导出答案 → 发给 AI 五维打分（结构 / 考察点覆盖 / 事例数据 / 精炼度 / JD 匹配度）→ 把点评粘回「AI 点评 / 复盘笔记」存档
- **掌握度追踪**：未练 → 已练 → 已掌握三级循环，实时掌握率进度条

## 使用方法

1. 下载 `job-tracker.html`
2. 双击用浏览器打开即可使用，**无需安装任何东西**

### 数据保存在哪？

数据存在浏览器的 `localStorage` 里，因此：

| 场景 | 说明 |
| --- | --- |
| 换浏览器 / 换电脑 | 数据**不会跟着走**，请先用「导出 JSON」备份，到新环境「导入」 |
| 换文件路径 | 换个文件夹打开，路径不同 = 独立存储空间，同样需要导出/导入 |
| 清理浏览器数据 | 会清空，务必先导出备份 |
| 想给别人看 | 用「导出 JSON」分享，或把 HTML 部署到静态托管 |

> 桌面端副本与项目内的文件是**两份独立存储**的，改动不会自动互相同步，建议固定只用一个入口。

## 技术说明

- **零依赖**：单个 HTML 文件，原生 JS + CSS，无框架、无构建步骤、无外部请求
- **存储**：`localStorage` 双 key —— `wb_jobtracker`（投递数据）、`wb_jobtracker_interview_v1`（面试 / 简历 / 定制题）
- **导出格式 v2**：`{ __version: 2, applications, interview }`，向下兼容旧版纯数组
- **交互**：原生 HTML5 Drag & Drop；全局事件委托（`data-action` / `data-iv-action`）
- **质量保障**：42 项自动化冒烟测试（岗位自适应 27 项 + 核心流程回归 15 项），每次迭代全量回归
